HARD ELEVATED GAP CHAINS — MATCHED Q-LEARNING COMPARISON

Open report.html for the Easy, Medium, and Hard comparison. findings.txt
summarizes the results and filming clips. summary.json contains checkpoint
wins, fastest, median and mean completion times, and training statistics.

All eight Hard agents started with empty Q-tables and seed 78436291. The
frozen code, settings and episode budget match Easy and Medium. Checkpoints
at 1,000, 5,000, and 10,000 training runs each got 30 frozen evaluations with
seeds 78436300–78436329. The empty table got 30 evaluations. Each attempt
used an eight-second stuck cutoff and a 60-second overall time limit.

The transfer-results folder contains two 30-run evaluations on Hard using
the same 5,000-run Easy checkpoints used in the Medium transfer test. The
transfer runs did not train or modify those Q-tables.

PLAYBACK
Open Playback recordings in the game and select an eval-XXXXX.mlpaths file
listed in the report. Each file contains the full 30-run batch. The training
recordings sampled one run every 100 training episodes.

REPRODUCE
Use run.py and source.zip from ../2026-11-20-easy-q-learning. Add --level hard
and specify a Godot 4.7.2 executable path with --godot. Run once for the
seven standard variants, once with --course-position, and once with
--untrained. Use fresh --output and --runtime directories for each.
Use analyze_hard.py --transfer --godot <executable> --runtime <scratch>
to repeat the transfer pair. Run analyze_hard.py with the completed archive
in place to regenerate the report.

Training win counts include exploration and learning. The separate frozen
checks compare the policies at three particular checkpoints from one
training seed and a fixed spawn per course.
