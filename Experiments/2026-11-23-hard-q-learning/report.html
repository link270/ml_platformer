Test protocol

All eight Hard agents started from empty tables with seed 78436291. Each frozen batch used evaluation seeds 78436300–78436329. Every course used a 60-second overall limit and an eight-second stuck cutoff that resets after a full block of best progress toward the orb.

The three course comparisons use one shared training seed and one fixed spawn per course. Frozen evaluation can repeat identical routes. Prior Medium and Easy policies were not used to initialize Hard training.
