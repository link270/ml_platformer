Protocol

Each trained agent started with an empty table and seed 78436291. It trained continuously for 10,000 episodes. Each frozen evaluation used seeds 78436300–78436329, paired across checkpoints and experiments. Identical runs can occur because the course and spawn are fixed. Stuck detection was enabled for all agents (8 simulation seconds with no new block of best progress); the overall timeout was 60 seconds.

The extra variant adds the signed horizontal distance to the orb in four-block bands to Fixed reward per block. On this course that also tells the agent roughly where it is. Its different Q-table schema requires the experiment worker, and its recordings play in the standard game. The staged training and evaluation data, recording metadata and checkpoint hashes were validated before this report was generated.
