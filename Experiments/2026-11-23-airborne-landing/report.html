Matched test

All variants start with empty tables on the same Hard course and seed 78436291. The frozen tests use seeds 78436300–78436329. Actions, decision timing, fixed reward, the 60-second limit, and the eight-second stuck cutoff match.

Landing memory keeps the last visible far lip from the grounded gap scan and bins the player's horizontal distance and vertical clearance while in the air. It clears on ground contact or reset. The original gap-ray preset uses the same grounded observations. The test uses one training seed and one fixed spawn.
