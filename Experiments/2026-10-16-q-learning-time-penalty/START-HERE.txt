WATCH A NEW POLICY WITHOUT REPLACING YOUR NORMAL SAVE
1. Extract experiment.zip outside the working game project.
2. In the extracted MainMenu.gd, change
     var checkpoint_path := Checkpoint.DEFAULT_PATH
   to (choose a seed/milestone):
     var checkpoint_path := "res://checkpoint-12345-10000.json"
3. Open the extracted project.godot in Godot 4.7.1 and run it.
4. Choose "Q-learning: evaluate saved". Evaluation keeps the table unchanged.
For baseline footage use the baseline archive's frozen project and matching table.

CONTINUE TRAINING
In the extracted experiment, run for example:
  sh ./train.sh --episodes 1000 --load ./checkpoint-12345-10000.json --save ./continued-checkpoint.json --save-every 100
Use a new save filename to preserve original results.
The checkpoint does not contain RNG state, so this is continued learning,
not an exact continuation of the original seeded sequence.

REPRODUCE
See REPRODUCE.txt inside experiment.zip. Training uses three fresh seeded agents,
not the old 16,988-episode saved agent. Diagnostic scripts are unchanged.
The comparison report uses the original saved baseline data, not a new baseline run.
Raw returns differ by definition and are not compared as a learning-quality metric.
Only three training seeds and one fixed map/spawn were tested; repeated greedy
runs often repeat the same path. This is not a statistical convergence claim.
.gdignore prevents Godot from importing archived scripts and resources.
