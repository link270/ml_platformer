Test protocol

Each Medium variant started with an empty Q-table and seed 78436291. Workers trained continuously through 10,000 runs. Each frozen batch used the same 30 evaluation seeds, 78436300–78436329. All runs had a 60-second limit and an eight-second stuck cutoff that resets after a full block of best progress toward the orb.

Each course has one tested training seed and one fixed spawn. Frozen evaluation can repeat identical routes. The two transfer clips test these particular tables and layouts.
